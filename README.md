# Kanami

把一台设备的声音，通过局域网实时送到另一台设备上播放。

## 状态

早期开发中（v0.1.0）。当前已落地的是**音频内核**与**协议层**，桌面/移动外壳尚未接入。

## 目标平台

| 平台 | 角色 | 状态 |
|---|---|---|
| macOS (arm64) | 发送 + 接收 | 开发自测平台 |
| Windows x64 | 发送 + 接收 | 由 CI 构建 |
| Linux x64 | 发送 + 接收 | 由 CI 构建 |
| Android | 接收 + 麦克风发送 | 开发自测平台 |
| iOS | 接收 | 第二阶段 |

## 三个模式

| 模式 | 帧长 | 码率 | 抖动缓冲 | 设计取舍 |
|---|---|---|---|---|
| 标准 | 20ms | 96 kbps CBR | 40–120ms 自适应 | 兼顾稳定与延迟 |
| 低延迟 | 10ms | 128 kbps | 固定 20ms | 宁可丢音，也要守住延迟承诺 |
| 高音质 | 20ms | 256 kbps VBR | 60–200ms 自适应 | 音乐优先，复杂度拉满 |

模式由**播放端**选择，音源端可以拒绝并降级。

## 架构

```
crates/
  kanami-proto/   协议：定长包头、消息编解码、模式参数表
  kanami-audio/   音频内核：混音、软限幅、抖动缓冲、漂移校正
src-tauri/        Tauri 外壳与平台适配（下一步）
```

音频内核不依赖 Tauri，可以脱离 UI 单独测试与用命令行验证。

## 开发

```bash
cargo test          # 内核单测
cargo clippy        # 静态检查
```

Windows/Linux 产物由 GitHub Actions 构建，本机只负责 macOS 与 Android。
